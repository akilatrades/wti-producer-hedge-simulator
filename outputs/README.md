# Generated Results

This folder contains saved analytical outputs produced by the WTI producer hedging and market-risk framework.

The project separates outputs into six decision areas:

1. fixed-ratio hedge effectiveness,
2. downside risk and P&L attribution,
3. Midland/Cushing basis risk,
4. minimum-variance hedge estimation and validation,
5. production-volume / hedge-ladder scenarios,
6. WTI term structure.

## Fixed-ratio hedge comparison

Core files:

- `hedge_ratio_summary.csv`
- `monthly_analysis.csv`
- `hedge_effectiveness.svg`
- `revenue_surprise_history.svg`

The saved historical sample shows:

| Hedge ratio | Revenue-surprise std. dev. | Hedge effectiveness |

## P&L attribution

Generated file:

- `pnl_attribution.csv`

The attribution separates:

```text
Physical flat-price effect
+ Futures hedge effect
= Residual flat-price result
```

The `attribution_check` field verifies that the decomposition reconciles to the hedge engine's reported revenue surprise.

## Midland/Cushing basis risk

Core file:

- `basis_risk_scenarios.csv`

The saved stress test assumes expected Midland basis of -$1/bbl and evaluates realized basis from +$1 to -$10/bbl under 0%, 50%, and 100% basis hedges.

This is a scenario analysis, not a historical basis backtest.

## Validation

The expanded analysis also generates:

## Production uncertainty and hedge ladder

Generated files:

- `production_uncertainty_scenarios.csv`

## Executive summary

`run_analysis.py` writes:

- `executive_summary.md`

This is a management-style summary intended to surface the key results, model validation, and residual risks without requiring a reader to inspect the underlying code first.

## Reproducing outputs

From the repository root:

```bash
pip install -r requirements.txt
python run_analysis.py
```

A manual GitHub Actions workflow is also provided to refresh generated outputs.

Historical results depend on the public data available at run time. See [data provenance](../data/README.md) and [model limitations](../docs/limitations.md).
