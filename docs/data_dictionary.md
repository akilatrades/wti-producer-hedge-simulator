# Data Dictionary

This page documents the primary analytical fields generated by the project.

## Hedge engine

| Field | Meaning |
|---|---|
| `spot_exit` | physical-price proxy at the end of the month |
| `futures_entry` | futures proxy used when the hedge is initiated |
| `futures_exit` | futures proxy when the hedge is closed |
| `hedge_ratio` | fraction of expected production hedged |
| `production_bbl` | expected physical production in barrels |
| `contracts_short` | whole CL contracts sold short |
| `hedged_bbl` | barrels represented by the futures position |
| `physical_revenue` | spot price × physical barrels |
| `futures_pnl` | short futures P&L |
| `hedged_revenue` | physical revenue + futures P&L |
| `benchmark_locked_revenue` | starting benchmark based on futures entry price |
| `revenue_surprise` | hedged revenue minus benchmark |

## Risk metrics

| Field | Meaning |
|---|---|
| `monthly_volatility` | standard deviation of monthly revenue surprise |
| `annualized_volatility` | monthly volatility scaled by sqrt(12) |
| `historical_var_95` | 95th percentile of historical modeled loss |
| `historical_es_95` | average loss at or beyond 95% VaR |
| `historical_var_99` | 99th percentile of historical modeled loss |
| `historical_es_99` | average loss at or beyond 99% VaR |
| `downside_deviation` | standard deviation of negative revenue surprises |
| `worst_loss` | largest historical modeled loss |

## P&L attribution

| Field | Meaning |
|---|---|
| `physical_flat_price_effect` | physical revenue relative to the entry-price benchmark |
| `futures_hedge_effect` | futures P&L |
| `residual_flat_price_effect` | sum of physical and futures flat-price effects |
| `basis_effect` | location-basis contribution when supplied |
| `total_residual_effect` | final residual after included components |

## Hedge ladder

| Field | Meaning |
|---|---|
| `production_month` | month expected physical barrels are produced/sold |
| `expected_production_bbl` | expected volume |
| `hedge_ratio` | policy hedge percentage for the month |
| `futures_contract` | illustrative contract label |
| `contracts_short` | whole CL contracts |
| `hedged_bbl` | volume represented by those contracts |
| `unhedged_bbl` | expected barrels not covered |
| `futures_price` | price used for illustrative notional |
| `hedge_notional` | hedged barrels × futures price |

## Term structure

| Field | Meaning |
|---|---|
| `contract_1`...`contract_4` | historical EIA WTI delivery-position prices |
| `c1_c2_spread` | C1 minus C2 |
| `c1_c3_spread` | C1 minus C3 |
| `c1_c4_spread` | C1 minus C4 |
| `curve_slope_per_contract` | average C4-C1 change per contract step |
| `curve_curvature` | C1 - 2×C2 + C3 |
| `c1_c4_zscore` | rolling z-score of the C1-C4 spread |
| `c1_c4_percentile` | expanding historical percentile rank |
| `curve_regime` | backwardation, contango, or flat |

## Validation

| Field | Meaning |
|---|---|
| `estimated_hedge_ratio` | ratio estimated from the trailing training window |
| `spot_change` | next-period spot price change |
| `futures_change` | next-period futures price change |
| `model_residual` | next-period residual using the estimated ratio |
| `one_to_one_residual` | next-period residual using a 1.0 hedge benchmark |
