# Glossary

| Term | Plain-English meaning |
|---|---|
| WTI | West Texas Intermediate, a major U.S. crude-oil benchmark. |
| CL | NYMEX WTI crude-oil futures ticker; one standard contract represents 1,000 barrels. |
| Physical crude | Actual oil produced, owned, transported, or sold. |
| Spot price | Cash-market price for near-term physical crude. |
| Futures contract | Standardized exchange-traded contract tied to a future delivery period. |
| Long | Exposure that generally benefits when price rises. |
| Short | Exposure that generally benefits when price falls. |
| Hedge | Position intended to reduce another economic exposure. |
| Hedge ratio | Portion of the physical exposure covered by the hedge. |
| Hedge effectiveness | Reduction in residual variance relative to the unhedged exposure. |
| P&L | Profit and loss. |
| P&L attribution | Decomposition of a total result into underlying drivers. |
| Basis | Price difference between two related locations, qualities, or instruments. |
| Basis risk | Risk that the physical price and hedge instrument do not move one-for-one. |
| Cushing | Oklahoma delivery hub associated with NYMEX WTI futures. |
| Midland | Major Permian Basin crude pricing location. |
| Revenue surprise | Difference between modeled hedged revenue and the starting benchmark. |
| Minimum-variance hedge ratio | Statistical hedge ratio that minimizes historical residual price-change variance. |
| Volatility | Dispersion of a price, P&L, or revenue series. |
| VaR | Value at Risk; a percentile threshold of modeled/historical loss. |
| Expected Shortfall | Average loss at or beyond a chosen VaR threshold. |
| Stress test | Analysis of a specified adverse scenario. |
| Continuous futures series | Long history created by linking successive futures contracts. |
| Futures curve | Prices of multiple futures delivery periods at one time. |
| Term structure | Another term for the futures curve. |
| C1 | Nearest delivery position in the historical EIA WTI futures series. |
| C2/C3/C4 | Next three delivery positions after C1. |
| Calendar spread | Difference between prices of two futures delivery positions. |
| Backwardation | Nearby futures priced above later futures. |
| Contango | Later futures priced above nearby futures. |
| Curve slope | Approximate change in price across delivery positions. |
| Curvature | Measure of how much the shape bends rather than following a straight slope. |
| Z-score | Number of standard deviations a value is from its rolling mean. |
| Hedge ladder | Schedule mapping future production periods to hedge percentages and contracts. |
| Over-hedging | Hedged volume exceeds realized physical volume. |
| Walk-forward test | Estimate a model on prior data and test it on the next unseen period. |
| Bootstrap | Resampling method used to estimate uncertainty around a statistic. |
| ETRM | Energy Trading and Risk Management system used for trade capture, positions, P&L, risk, and settlements. |
